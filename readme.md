# 💻 Project: Team CodeHelp Web Page

This is a responsive web page built using **HTML** and **CSS**, showcasing the **Team CodeHelp** section. It includes a navigation bar, content layout with images and text, and a clean, minimal design suitable for personal or educational websites.

- 🧑‍💻 "About Team" section with image and bio
- 📌 Navigation bar with links to:
  - Team
